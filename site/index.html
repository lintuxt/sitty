sitty

si + tty — say it “city”

A terminal built to host AI harnesses — and to be hacked by them.

An open-source macOS terminal for Claude Code, Codex, Aider and your own scripts. Harnesses can open panes, show you what they’re doing, talk to each other in a shared channel, and everything keeps running when you close the window.

  • Any harness

    Claude Code, Codex, Aider or a shell script. If it runs in a terminal, it runs in sitty.

    Every harness, the panes it opened and what it’s doing right now, in one sidebar.
